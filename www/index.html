ReactorNet

A minimalist C++ network library inspired by muduo. Epoll-driven, non-blocking I/O, with timer heap and multi-reactor threading.

Epoll Event-Driven

High-performance I/O multiplexing via epoll, supporting thousands of concurrent connections.

Timer Heap

Min-heap timer management using timerfd for precise, kernel-level timeout handling.

Read/Write Buffers

Efficient buffer management with scatter/gather I/O to handle TCP framing.

Multi-Reactor Threading

One loop per thread with round-robin connection distribution for CPU scalability.

HTTP 1.0 Server

Built-in static file serving with URL decoding and path traversal protection.

Zero Dependencies

Pure Linux system calls — no Boost, no libevent, no third-party libraries.

Quick Start

$ mkdir -p build && cd build && cmake .. && make -j$(nproc)
$ ./reactor_demo           # Echo server on port 8080
$ ./reactor_demo 4         # Multi-threaded echo (4 workers)
$ ./reactor_demo http      # HTTP server on port 8080
$ ./reactor_demo http 4    # Multi-threaded HTTP (4 workers)

Modules

  • EventLoop — Per-thread event loop with cross-thread task dispatch
  • EPollPoller — Epoll-based I/O multiplexing
  • Channel — Event dispatcher (fd + callbacks)
  • TimerQueue — Min-heap timer management with timerfd
  • TcpConnection — TCP connection with input/output buffers
  • TcpServer — Multi-reactor server with accept loop
  • Acceptor — Listening socket handler
  • Buffer — Non-contiguous read/write buffer
  • HttpRequest/HttpResponse — Simple HTTP 1.0 parser
Built with epoll + non-blocking I/O on Linux. No external dependencies.
